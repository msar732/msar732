Trade India API Documentation

Overview

The Trade India API provides programmatic access to our trading platform. Build mobile apps, integrations, or custom interfaces using our REST API.

Base URL

{{ request.build_absolute_uri }}/api/

Authentication

The API supports both session-based and token-based authentication.

Authorization: Token your-api-token

Endpoints

Listings API

Method Endpoint Description
GET /api/listings/listings/ List all active listings
POST /api/listings/listings/ Create a new listing
GET /api/listings/listings/{id}/ Get listing details
PUT /api/listings/listings/{id}/ Update listing
DELETE /api/listings/listings/{id}/ Delete listing
POST /api/listings/listings/{id}/favorite/ Toggle favorite status
POST /api/listings/listings/{id}/inquire/ Send inquiry

Categories API

Method Endpoint Description
GET /api/listings/categories/ List all categories
GET /api/listings/categories/{id}/ Get category details

Locations API

Method Endpoint Description
GET /api/locations/states/ List all Indian states
GET /api/locations/districts/ List districts (filter by state)
GET /api/locations/cities/ List cities (filter by district)

Query Parameters

Parameter Type Description
search string Search in title, description, tags
category integer Filter by category ID
state integer Filter by state ID
district integer Filter by district ID
min_price decimal Minimum price filter
max_price decimal Maximum price filter
listing_type string sell, buy, exchange, rent, service
ordering string created_at, -created_at, price, -price

Example Requests

Get all listings
GET /api/listings/listings/
Search for iPhones in Mumbai
GET /api/listings/listings/?search=iphone&state=21&district=1
Create a new listing
POST /api/listings/listings/
